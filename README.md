# کافه سه‌بعدی ☕

یک بازی کافه‌داری سه‌بعدی تحت وب با three.js. باریستا رو با کلیک/لمس بین وسایل جابه‌جا کن،
قهوه و غذا آماده کن و قبل از تموم شدن حوصله‌ی مشتری تحویلش بده.

## اجرا

```bash
npm install
npm run dev      # سرور توسعه
npm run build    # خروجی نهایی در dist/
```

برای دستگاه‌های ضعیف `?low` رو به آخر آدرس اضافه کن (سایه خاموش، رزولوشن کمتر).

## منو

- **قهوه:** اسپرسو، آمریکانو، لاته، کاپوچینو، موکا، آیس لاته، آیس آمریکانو
- **غذا:** تست، تست بیکن، تست پنیر، برگر، چیزبرگر

آیتم‌های جدید از روز ۲ و ۳ باز می‌شن. دستور هر کدوم داخل بازی، دکمه‌ی «📖 دستورها».

## ساختار کد

| فایل | کار |
|---|---|
| `src/main.js` | حلقه‌ی بازی، باریستا، مشتری‌ها، منطق ایستگاه‌ها، رابط کاربری |
| `src/world.js` | چیدمان کافه، نور، ایستگاه‌های قابل‌کلیک |
| `src/props.js` | مدل‌های ساخته‌شده با کد: دستگاه اسپرسو، آسیاب، کتری، توستر، فنجان، بیکن، نان |
| `src/assets.js` | بارگذاری مدل‌های GLTF و انیمیشن کاراکترها |
| `src/data.js` | منو و دستور پخت‌ها |
| `src/audio.js` | افکت‌های صوتی ساخته‌شده با WebAudio |

## مدل‌ها

مدل‌های محیط، مبلمان و کاراکترها از پک‌های [KayKit](https://kaylousberg.itch.io) اثر Kay Lousberg هستن
(Restaurant Bits، Furniture Bits، Adventurers) با لایسنس **CC0**. انیمیشن‌های استفاده‌نشده‌ی
کاراکترها برای کم شدن حجم حذف شدن.
